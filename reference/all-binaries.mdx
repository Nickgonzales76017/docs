Bonfyre ships 48 static C11 binaries totaling approximately 2.1 MB on disk. Every binary does one job, starts in under 50 ms, and stays under 70 KB. They compose via pipes and files, and all link against `libbonfyre` for a shared artifact contract. This page is the complete catalog organized by category.

<Note>
`liblambda-tensors` is a **library** (static `.a` and shared `.so`), not a binary. It does not appear in the binary tables below. See the [Lambda Tensors reference](/reference/lambda-tensors) for its API.
</Note>

## Common flags

Most binaries accept the following flags regardless of category:

| Flag | Description |
|---|---|
| `--help` | Print usage information and exit |
| `--version` | Print the binary's version string and exit |
| `status` | Print system information: build flags, operator descriptor, SQLite path (if stateful), and runtime environment |

## Layer model summary

Binaries are classified by behavioral contract into four layers. The layer determines what a binary is allowed to import and how it declares its operator flags.

| Layer | Binaries | Contract |
|---|---|---|
| **Surface** | cms, api, auth, pipeline, cli, transcript-family, project | Product-facing and stateful. Own mutable state and serve HTTP or complex CLI interfaces. |
| **Value** | offer, gate, meter, ledger, finance, outreach, pay, pack, distribute | Monetization, metering, and delivery. Separate privilege boundary. |
| **Transform** | media-prep, transcribe, transcript-clean, paragraph, brief, proof, embed, narrate, render, emit, mfa-dict, weaviate-index | Pure and cacheable. Same inputs always produce the same outputs. |
| **Substrate** | ingest, hash, index, compress, stitch, graph, runtime, queue, sync | Cold infrastructure. Never import product concepts. |

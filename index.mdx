## Get running in 4 steps

<Steps>
  <Step title="Install Bonfyre">
    Clone and build all binaries — requires only a C11 compiler, SQLite3 headers, and zlib.
    ```bash
    git clone https://github.com/Nickgonzales76017/bonfyre-oss.git
    cd bonfyre-oss && make && make install
    ```
  </Step>
  <Step title="Populate the registries">
    Sync the CLI and populate workflow, recipe, and layer registries after the first build.
    ```bash
    bonfyre doctor sync-subcommands
    bonfyre list --health
    ```
  </Step>
  <Step title="Run your first pipeline">
    Process an audio file end-to-end — transcript, summary, and ZIP deliverable in 5–8 ms.
    ```bash
    bonfyre-pipeline run --input interview.mp3 --out ./output
    ```
  </Step>
  <Step title="Explore what's available">
    Browse the full binary catalog and check which commands are healthy.
    ```bash
    bonfyre list --health
    bonfyre workflow list
    bonfyre recipe list
    ```
  </Step>
</Steps>
